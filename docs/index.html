What you are hearing

A pretrained symbolic music transformer is fine-tuned with a gated cross-attention adapter that reads a learned embedding for each pianist. Unlike a prompt prefix, whose influence fades as generation continues, this channel stays available at every step, so the conditioning persists through long continuations.

We measure that with a classifier trained to identify the twelve pianists (95.8 % per chunk, 98.8 % per track). Sliding it along generated music, conditioned continuations are attributed to the intended pianist far more often than unconditioned ones. A second classifier trained only on generated performances then identifies real recordings with 95 % song-level accuracy — the generated music carries stylistic structure that transfers back to human playing.

Built on Aria and the PiJAMA dataset. Research tool for studying pianist style, not a system for imitation at anyone’s expense — see the paper’s ethics discussion.
